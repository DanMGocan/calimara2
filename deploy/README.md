# Server configuration (calimara.ro VM)

Copies of the files installed outside the repo, for reference and re-installation.

| File | Installed at | Purpose |
|------|--------------|---------|
| `systemd/calimara-backup.{service,timer}` | `/etc/systemd/system/` | Daily 03:30 `scripts/backup_db.py` → Hetzner Object Storage `backups/db/`, keeps newest 3 |
| `systemd/calimara-cloudflare-sync.{service,timer}` | `/etc/systemd/system/` | Weekly refresh of Cloudflare IP ranges |
| `sbin/calimara-cloudflare-sync` | `/usr/local/sbin/` | Writes nginx real-IP config; UFW allows 80/443 only from Cloudflare (SSH untouched) |
| `nginx/security-headers.conf` | `/etc/nginx/conf.d/` | HSTS, nosniff, frame-ancestors, Referrer-Policy, Permissions-Policy |

`calimara.service` itself is generated by `run.py`; the site config by `scripts/setup_nginx.sh` (Cloudflare mode).

Restore a backup: `pg_restore --clean --no-owner -d calimara_db calimara_db-<stamp>.dump`
